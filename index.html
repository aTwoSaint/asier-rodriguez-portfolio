Prácticas de desarrollo web

Bic Graphic · Octubre de 2024 – Enero de 2025

Participé, con la orientación de un responsable, en el desarrollo de una aplicación web interna para consultar y gestionar datos de la empresa. Trabajé en estas partes:

  • Interfaz frontend con React.
  • Backend con Node.js y una API, sobre una base de datos SQLite.
  • Inicio de sesión y acceso restringido.
  • Tabla para consultar los datos y filtrarlos por palabra.
  • Operaciones CRUD: añadir, editar y eliminar registros.
  • Pruebas y validaciones con Mocha y Postman.
